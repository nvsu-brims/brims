# Welcome to NVSU-BRIMS 👋

> NVSU-BRIMS is the Nueva Vizcaya State University Borrowing and Returning Items & Equipment Management System. It replaces logbooks and walk-in requests with one web platform for the Sports Development Office and the University Culture and the Arts Office. Borrowers browse the catalog and request items, and office admins approve requests, track borrowed items, manage inventory and users, and review activity logs. Built with Next.js, Prisma and Supabase.

## Install

```sh
npm install
```

## Usage

```sh
npm run dev
```
